# DARWIN identity

## Concept

The **adaptive D** contains three competing branches. Two terminate inside the
system; one crosses the boundary and leaves a signal. It is a compact expression
of DARWIN's product loop: variation, selection, and memory.

The wordmark is custom-drawn as SVG paths. It has no font dependency.

## Files

- `darwin-logo-primary.svg` — default monochrome lockup for light backgrounds.
- `darwin-logo-reverse.svg` — light lockup for dark backgrounds.
- `darwin-logo-accent.svg` — optional copper survivor signal.
- `darwin-logo-stacked.svg` — centered lockup for square formats.
- `darwin-mark.svg` — icon-only adaptive D.
- `darwin-favicon.svg` — optically simplified mark for 16–32 px use.
- `darwin-wordmark.svg` — text-only custom wordmark.
- `darwin-logo-board.svg` — presentation board, not a production asset.

## Palette

- Ink: `#12110F`
- Bone: `#F2EFE7`
- Survivor copper: `#D48F66`

## Usage

- Prefer the monochrome primary or reverse lockup.
- Use the copper survivor only as a product-state accent.
- Preserve clear space equal to half the height of the D.
- Minimum recommended width: 140 px for the lockup, 48 px for the full icon.
- Below 48 px, use `darwin-favicon.svg`.
- Do not add shadows, gradients, outlines, or extra typography.
